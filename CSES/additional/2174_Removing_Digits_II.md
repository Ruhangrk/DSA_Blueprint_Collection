## Problem Statement

Given `n`, each step subtracts any one-digit number (1 to 9) that appears in the current number. Find the fewest steps to reach `0`.

### Input

- One line with `n`.

### Output

One integer: the minimum number of steps.

### Constraints

- `1 <= n <= 1e18`

### Examples

**Input**
```
27
```

**Output**
```
5
```

Explanation: `27 -> 20 -> 18 -> 10 -> 9 -> 0`.
