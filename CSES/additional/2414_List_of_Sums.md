## Problem Statement

List `A` has `n` positive integers. List `B` holds every pairwise sum `A[i] + A[j]` for `i < j`. Given `B`, reconstruct `A`. Each value in `A` lies in `1..k`.

### Input

- The first line has `n`.
- The next line has `n(n-1)/2` integers: list `B`.

### Output

`n` integers: list `A`, in any order.

### Constraints

- `3 <= n <= 100`
- `1 <= k <= 1e9`

### Examples

**Input**
```
4
4 4 4 6 6 6
```

**Output** (one valid answer)
```
1 3 3 3
```
