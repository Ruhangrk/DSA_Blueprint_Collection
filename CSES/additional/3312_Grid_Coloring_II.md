## Problem Statement

An `n x m` grid has a letter `A`, `B` or `C` in each cell. Change every cell to a letter different from its current one, so that no two adjacent cells share a letter. Print the new grid, or `IMPOSSIBLE`.

### Input

- The first line has `n` and `m`.
- Next `n` lines describe the grid.

### Output

`n` lines with `m` letters, or `IMPOSSIBLE`.

### Constraints

- `1 <= n, m <= 500`

### Examples

**Input**
```
3 4
AAAA
CCBB
ABCA
```

**Output** (one valid answer)
```
BCBC
ABCA
CABC
```
