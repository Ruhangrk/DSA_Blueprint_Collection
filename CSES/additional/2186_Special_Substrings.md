## Problem Statement

A substring is special if every character appearing in it appears the same number of times. Count the special substrings of a given string.

### Input

- One line with the string (`a` to `z`).

### Output

One integer: the count of special substrings.

### Constraints

- `1 <= n <= 2e5`

### Examples

**Input**
```
abccabab
```

**Output**
```
5
```

Explanation: `abc`, `cab`, `abccab`, `bccaba`, `ccabab`.
