## Problem Statement

A `2 x n` grid has `2n` coins spread across cells, with `2n` coins in total. Move coins one step at a time (left, right, up or down) so that every cell holds exactly one coin. Print the minimum number of moves.

### Input

- The first line has `n`.
- Two lines, each with `n` integers: the coin counts in each row.

### Output

One integer: the minimum number of moves.

### Constraints

- `1 <= n <= 1e5`

### Examples

**Input**
```
4
0 1 0 1
2 0 1 3
```

**Output**
```
5
```
